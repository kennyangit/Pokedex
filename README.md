<p>Uma Pokédex interativa desenvolvida com HTML, CSS (Tailwind) e JavaScript, utilizando a PokéAPI para buscar informações dos Pokémons.
</br></br>Este projeto foi criado para aprofundar conhecimentos em front-end, responsividade, animações, consumo de API e dark mode.</p>

<h3>🚀 Funcionalidades</h3>

<ul>
  <li>Listagem dos 151 Pokémon da primeira geração</li>
  <li>Informações detalhadas</li>
  <li>Filtro por tipos</li>
  <li>Barra de pesquisa</li>
  <li>Modo escuro</li>
  <li>Layout totalmente responsivo</li>
  <li>Informações completas via PokéAPI</li>
</ul>
